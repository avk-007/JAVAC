### How to use this roadmap:
Solve in order. For each problem, first understand it, create examples, attempt a brute-force approach, dry-run it, write Java code, test edge cases, analyze time/space complexity, and then optimize.
**Progression:** Java fundamentals → logic → strings → arrays → collections → core DSA → advanced algorithms → dynamic programming → interview-level problems.
