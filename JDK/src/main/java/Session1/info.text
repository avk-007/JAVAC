Primitive Functional Interfaces (Java 17)
=========================================

There are 4 categories of primitive functional interfaces.

----------------------------------------------------------
1. Primitive Input Functional Interfaces
----------------------------------------------------------
These interfaces take a primitive as input and return a generic type.

1. IntFunction<R>
   R apply(int value)

2. LongFunction<R>
   R apply(long value)

3. DoubleFunction<R>
   R apply(double value)

----------------------------------------------------------
2. Primitive Output Functional Interfaces
----------------------------------------------------------
These interfaces take a generic type as input and return a primitive.

1. ToIntFunction<T>
   int applyAsInt(T value)

2. ToLongFunction<T>
   long applyAsLong(T value)

3. ToDoubleFunction<T>
   double applyAsDouble(T value)

----------------------------------------------------------
3. Both Input and Output are Primitive
----------------------------------------------------------
These interfaces take one primitive input and return another primitive.

Input: int

1. IntToLongFunction
   long applyAsLong(int value)

2. IntToDoubleFunction
   double applyAsDouble(int value)

Input: long

3. LongToIntFunction
   int applyAsInt(long value)

4. LongToDoubleFunction
   double applyAsDouble(long value)

Input: double

5. DoubleToIntFunction
   int applyAsInt(double value)

6. DoubleToLongFunction
   long applyAsLong(double value)

----------------------------------------------------------
4. Primitive Output BiFunction Interfaces
----------------------------------------------------------
These interfaces take two generic inputs and return a primitive.

1. ToIntBiFunction<T, U>
   int applyAsInt(T t, U u)

2. ToLongBiFunction<T, U>
   long applyAsLong(T t, U u)

3. ToDoubleBiFunction<T, U>
   double applyAsDouble(T t, U u)
